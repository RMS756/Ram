# Reproducing the Exploratory Pilot

All pilot outputs are labelled **EXPLORATORY — NOT THESIS RESULTS — SUPERVISOR DECISION REQUIRED**.

## Requirements

- Python ≥ 3.10, with `numpy`, `PyYAML`, `pytest`, `matplotlib`, and `agentdojo==0.1.35` (PyPI).
- AgentDojo repository at commit `089ed468cf3ed0322acc66b0211f26d9d90dbf60`, for its `runs/` directory of recorded real-LLM traces. Set `AGENTDOJO_RUNS=/path/to/agentdojo/runs`. The default is `/home/user/ethz-spylab/agentdojo/runs`.
- No LLM API key and no credentials are needed. Every tool call executes in AgentDojo's simulated banking environment.

## Steps

```bash
pip install -e .[dev] agentdojo==0.1.35 matplotlib
python -m pytest -q                         # 192 passed (without agentdojo: 189 passed, 1 module skipped)
PYTHON=python experiments/pilot/run_all.sh  # about 10 min on 4 cores; writes results/pilot/
bash thesis/build.sh                        # pandoc + Chromium (Playwright) -> thesis/build/
```

## Outputs and provenance

| File | Content |
|---|---|
| `results/pilot/dataset_summary.json` | Episodes, steps, labels, label/outcome consistency, exclusions |
| `results/pilot/e0_pilot.json` | Pilot E0 (fitting portions only) |
| `results/pilot/e1_crossfit.json` | Discrimination and calibration; per-fold results; ablation refits; grouping sensitivity; leave-one-backbone-out |
| `results/pilot/e2_e5_e6_observe_only.json` | Observe-only verdicts, ablations, dominance check, E6 grid |
| `results/pilot/e4_rmod_and_replay_validity.json` | Replay agreement; r_mod (replay, SC-7) |
| `results/pilot/e4_e5_enforcement_replay.json` | Enforcement replay (SC-7): ASR, utility, paired differences, per backbone, latency |
| `results/pilot/e3_a2_cusum_observe_only.json` | Observe-only CUSUM |
| `results/pilot/e4_cross_template_and_defenses.json` | Other templates (gpt-4o); recorded outcomes of the distributed defenses |
| `results/pilot/sensitivity_post_hoc_exclude_user_task_15.json` | Disclosed post-hoc sensitivity |
| `results/pilot/benign_release_breakdown.json` | Benign-episode verdicts by tier |
| `results/pilot/latency_memory_profile.json` | Per-step memory |
| `results/pilot/label_audit_sample.md` | 30-episode label audit sample |
| `results/pilot/figures/` | Reliability diagram; enforcement replay figure |

Every JSON records:
- the label;
- the REM git commit;
- the SHA-256 of the pilot configuration and of the amendments;
- the AgentDojo package version and `runs/` commit;
- the Python and NumPy versions.

Intermediate state (`results/pilot/state/`, `results/pilot/steps.pkl`) is regenerated by the script and is not committed.

## Determinism

All randomness is seeded (`meta.seed` = 20261027). Two complete runs from commit `aa66f22` produced identical outputs.
