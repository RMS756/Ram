## 1. Question

**Does REM v1.0 behave as Defense in Depth?** Specifically: when one of its evidence controls is defeated by an attacker, do its other controls still lead the decision to withhold the attack-labeled call?

Five architectural layers are not assumed to give depth. Depth is measured.

## 2. Controls examined (all implemented in REM v1.0)

| ID | Control | Layer | Signal "fires" when | Value when evaded |
|---|---|---|---|---|
| K2 | Instruction-pattern indicator x~ctx2~ | Detection | x~ctx2~ = 1 | 0 |
| K3a | Post-observation shift x~beh1~ | Behavioral Analysis | x~beh1~ = 1 | 0 |
| K3b | Repeated calls x~beh2~ | Behavioral Analysis | x~beh2~ > 1/n~max~ (a repeat, I-2) | 1/n~max~ |
| K3c | Privilege escalation x~beh3~ | Behavioral Analysis | x~beh3~ = 1 | 0 |
| K3d | Transition deviation x~beh4~ (fold's benign reference) | Behavioral Analysis | x~beh4~ = 1 | 0 |
| K4 | Argument provenance x~act1~ | Behavioral Analysis (action evidence; labels from Input & Context) | x~act1~ = 1 | 0 |
| K5 | Destination novelty x~act2~ (I-5: recipient not in the user objective) | Behavioral Analysis (action) | x~act2~ = 1 | 0 |
| K6 | Sensitive egress x~act3~ | Behavioral Analysis (action) | x~act3~ = 1 | 0 |
| K7 | Learned expected-loss decision | Decision Engine | verdict ∈ {Modify, Escalate, Block} (withhold, step-level, no reviewer) | — (outcome variable) |
| K8 | Predicates D1/D2 | Decision Engine | verdict source D1 or D2 | not evadable by feature suppression |
| K9 | Enforcement | Mitigation | all withholding verdicts are enforced | — |

**Not examined:** the injection classifier x~ctx1~, which is not implemented (D-8), and the Input & Context labels, which are not a decision signal of their own.

## 3. Data

- **Steps:** the 6,762 held-out steps of the primary population (921 attack-labeled), from `steps.pkl`, regenerated by the unchanged pilot code.
- **Reproduction gate (verified before this protocol):** `dataset_summary.json` equals `results/pilot_R4/dataset_summary.json` on every field.
- **Models:** the nine outer-fold models of the re-run of the frozen pilot cross-fitting (label-NLL calibration, step-level policy, no reviewer).
- **Second reproduction gate:** the pooled held-out ROC-AUC and the per-fold λ and γ must equal `results/pilot_R4/e1_crossfit.json`. Likewise, the REM v1.0 step-level observe-only verdict counts must equal `results/pilot_R4/e2_e5_e6_observe_only.json`. **If either differs, the analysis stops** and the difference is reported.
- **Primary analysis set:** attack-labeled steps whose tool is in 𝒯~R~ (state-changing). The same quantities are also reported for all attack-labeled steps.
- **Cost reference:** legitimate (y = 0) steps of 𝒯~R~ tools.

## 4. Analyses

| ID | Analysis | Content |
|---|---|---|
| A1 | Coverage and redundancy | For every attack-labeled step: the set of evidence controls K2–K6 that fire, and their number r. Report the distribution of r; the steps with r = 0 (no evidence) and r = 1 (single point of failure), by control; and each control's firing rate on attack-labeled and on legitimate 𝒯~R~ steps (cost of each control). |
| A2 | Single-control evasion | For each control k in {K2, K3a, K3b, K3c, K3d, K4, K5, K6}: set its feature to the evaded value on attack-labeled steps only. Recompute the calibrated probability with the frozen held-out fold model, then REM v1.0's verdict with the unchanged policy. Report the attack-labeled 𝒯~R~ steps withheld, against the unevaded baseline. Legitimate steps are unchanged by construction. |
| A3 | Group evasion | As A2, for the evidence groups ctx (K2), beh (K3a–d) and act (K4–K6), and for every pair of groups |
| A4 | Pairwise evasion | As A2, for every pair of the eight evidence controls (28 pairs) |
| A5 | Single-control rules for contrast | P1 (withhold iff K4) and P2 (iff K4 or K5) under the same evasions. They have no depth by design and show what depth would add. |
| A6 | Predicates | The number of attack-labeled steps whose verdict is fixed by D1 or D2. These are unaffected by evasion. |

**Uncertainty.** Counts are reported with 95% grouped-bootstrap intervals (2,000 resamples, seed 20261027, clusters = injection task) for the withheld fraction under each evasion. No hypothesis test is planned, and no pass or fail threshold is defined: no approved criterion for "sufficient depth" exists, and none is invented.

## 5. Interpretation rules (fixed in advance)

- **Depth against evading control k** is described by the withheld fraction under its evasion, beside the baseline. A fraction close to the baseline is described as "other controls compensate for k on these steps". A large drop is described as "a single point of failure in k on these steps".
- **Steps with r = 1** are reported as single points of failure in the evidence, whatever the learned decision does.
- **Results describe REM v1.0's evidence and decision rule on recorded steps.** They are not claims about attack success in replay or against live agents.

## 6. Known limitations (stated before results)

1. **Idealized, independent evasion.** Suppression sets one signal to its not-fired value and leaves the others unchanged. A real evasion could change several features at once, or none completely.
2. **Observe-only, step-level.** There is no replay, no agent adaptation and no episode outcome. A2–A4 measure decisions on calls, not attack success.
3. **No refitting.** The attacker evades at test time, so the fitted coefficients are unchanged. This is the threat model of evasion, not of training-time ablation.
4. **Labels are reference-matched attempt labels** (not human-audited).
5. **Development data.** These steps were used to design REM v1.0.
6. **One benchmark**, with one attacker account. K5 fires on the attacker's recipient by construction of the benchmark (the attacker account never occurs in a user objective).
