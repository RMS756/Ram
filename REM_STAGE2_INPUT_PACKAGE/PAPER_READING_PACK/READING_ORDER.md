# READING ORDER

**This is a reading sequence, not a ranking.** The order follows REM's own pipeline: the threat, then the evaluation environment, the estimator, calibration, the decision rule, the audit record, and finally the prior systems that combine these parts, then the financial domain. Each paper is placed after the papers it builds on, so it can be understood when you reach it. No paper is ranked as more or less important than another.
